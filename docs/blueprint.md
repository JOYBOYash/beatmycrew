# **App Name**: BeatMyCrew

## Core Features:

- Room Creation/Joining: Generate a unique 5-character room code or join an existing room using a given code.
- Character Pool Generation: Generate a random pool of 50 One Piece characters from which players will draft.
- Drafting Phase: Players take turns drawing characters randomly from the list of one piece characters they have to assign each of them that they draw under a role in their crew
- Team Building: Assign randomly drawn characters to specific positions (Captain, Vice Captain, etc.) within the crew.
- Vote-off Phase: Players rate each other's teams on a scale of 1-10. Calculate average scores.
- Winning Display: Show the team with the highest average score.

## Style Guidelines:

- Primary color: Sandy Yellow (#F4D03F) to represent the desert sands where Alabasta resides.
- Background color: Pale Sand (#FAF7EC). A muted sandy hue for a calm backdrop.
- Accent color: Sea Blue (#3498DB) to highlight interactive elements and represent the sea that connects the One Piece world. This will be a good visual contrast to the light sand palette.
- Body text: 'PT Sans', sans-serif.
- Headlines: 'Playfair', sans-serif. Use for titles.
- Use One Piece-themed icons for team positions, actions (swap, pass), and voting.
- Implement a clean and intuitive layout with distinct sections for room info, character pool, drafting area, and team view.
- Use smooth transitions and subtle animations to enhance user experience during drafting, voting, and win celebration.
